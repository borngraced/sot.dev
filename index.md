I’m Samuel, a software engineer in Lagos. I mostly write Rust and Go, usually working on backend systems, developer tools, and low-level stuff.

I've spent the last few years working on [Komodo](https://komodoplatform.com/en/docs/start-here/core-technology-discussions/komodo-defi-framework/), where I worked on wallets, atomic swaps, WalletConnect, WebAssembly, and Zcash/ARRR. I also built the backend for [Khoomi](https://khoomi.com/about), a handmade marketplace, and previously built [DDW](https://www.dontdiewondering.com).

Outside work, I contribute to projects I use or find interesting. Some of that has landed in [REVM](https://github.com/bluealloy/revm), [Rust Clippy](https://github.com/rust-lang/rust-clippy), and [Slint](https://github.com/slint-ui/slint).

A few things I've worked on:

- [Komodo DeFi Framework](https://komodoplatform.com/en/docs/start-here/core-technology-discussions/komodo-defi-framework/): Rust and Go infrastructure around wallets, atomic swaps, WebAssembly, Zcash/ARRR, HD-wallet signing, and WalletConnect
- [Khoomi](https://khoomi.com/about): designed and built the backend for a multi-vendor marketplace in Go, including orders, inventory, shipping, seller wallets, and payouts
- [DDW](https://www.dontdiewondering.com): built the magazine website with Next.js and TypeScript, including memberships, gated content, and CMS-backed publishing
- [REVM](https://github.com/bluealloy/revm): Rust performance work, including a [7.9x faster JumpTable lookup](https://github.com/bluealloy/revm/pull/2618) and an [8.65% benchmark improvement](https://github.com/bluealloy/revm/pull/2634)
- [Slint](https://github.com/slint-ui/slint): optimized WGPU startup so unused GL/Mesa backends aren't loaded unnecessarily ([#13261](https://github.com/slint-ui/slint/pull/13261))
- [Rust Clippy](https://github.com/rust-lang/rust-clippy): added the [`needless_type_cast`](https://github.com/rust-lang/rust-clippy/pull/16139) lint
- [awari](https://github.com/borngraced/awari): a Wayland launcher built on GPUI
